¿Qué es FlowLab?
Contexto del proyecto

FlowLab es un orquestador visual de flujos que permite crear diagramas de procesos ejecutables. El comparador de precios se integra como:

  • Nodo ejecutable dentro de FlowLab (tipo: price-comparison)
  • Módulo independiente en la arquitectura modularizada (19 archivos)
  • Página web accesible desde http://localhost/paginaRE/pages/price-comparison.html
  • Datos compartidos a través del objeto STATE global
