🤖 Configurar Qwen Coder

Conecta los modelos reales de Qwen en VS Code

1
Crear cuenta en DashScope
Accede a la plataforma de Alibaba Cloud para obtener tu API key
¿Qué es DashScope?
DashScope es la plataforma oficial de Alibaba Cloud que proporciona acceso a los modelos reales de Qwen (qwen-max, qwen-plus, qwen-turbo, qwen2.5-coder-32b-instruct, etc.)

Pasos:

  1. Abre tu navegador y ve a: https://dashscope.aliyun.com
  2. Si no tienes cuenta, haz clic en "Sign Up" o "Registrarse"
  3. Completa el registro (necesitarás email o cuenta de Alibaba)
  4. Una vez dentro, confirma tu email si lo pide
💡 Nota: Si tienes problemas con el registro desde España/Latinoamérica, puedes usar un VPN temporal o usar tu cuenta de Google/GitHub si está disponible.
→ Ir a DashScope
2
Generar una API Key
Obtén las credenciales para conectar Qwen Coder con los modelos reales

En DashScope:

  1. Haz clic en tu perfil (esquina superior derecha)
  2. Busca "API Keys" o "API Settings" en el menú
  3. Haz clic en "+ Create API Key" o "+ Nueva API Key"
  4. Dale un nombre descriptivo (ej: "Qwen Coder VS Code")
  5. Copia la API Key que se genera (la verás una sola vez)
  6. Guárdala en un lugar seguro (la necesitarás en el siguiente paso)
🔐 Importante: Esta API Key es confidencial. No la compartas públicamente. Si la pierdes, puedes generar una nueva en cualquier momento desde DashScope.
✅ Tu API Key tendrá este formato:
sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
3
Configurar en VS Code
Introduce tu API Key en la extensión Qwen Coder

Opción A: Command Palette (Recomendado)

  1. Abre VS Code
  2. Presiona Ctrl + Shift + P
  3. Escribe: Qwen: Set API Key
  4. Si no aparece ese comando, escribe: Qwen: Configure
  5. Se abrirá un cuadro de entrada
  6. Pega tu API Key (la que copiaste en el paso anterior)
  7. Presiona Enter
💡 Nota: Si ninguno de esos comandos aparece, usa la Opción B (configuración manual) más abajo.

Opción B: Configuración Manual

Si los comandos de Qwen no aparecen, puedes configurar la API Key directamente en settings.json:

  1. Presiona Ctrl + Shift + P
  2. Escribe: Preferences: Open Settings (JSON)
  3. Se abrirá tu archivo settings.json
  4. Añade estas líneas dentro del objeto JSON:
  "qwen.apiKey": "sk-YOUR_API_KEY_HERE",
  "qwen.apiEndpoint": "https://dashscope.aliyuncs.com/api/v1",
  "qwen.model": "qwen2.5-coder-32b-instruct"
  1. Reemplaza sk-YOUR_API_KEY_HERE con tu API Key real
  2. Guarda el archivo (Ctrl + S)
  3. Reinicia VS Code o recarga la ventana (Ctrl + Shift + P → "Reload Window")
4
Verificar que Funciona
Prueba que Qwen Coder puede acceder a los modelos reales

En VS Code:

  1. Presiona Ctrl + Alt + I (o ejecuta "Qwen Code: Focus on Qwen Code View")
  2. Se abrirá el panel de Qwen Coder en la derecha o abajo
  3. Mira el selector de modelos (ahora debería mostrar modelos reales)
  4. Si ves esto = ✅ Éxito:
qwen2.5-coder-32b-instruct Recomendado para código
qwen-max Modelo más potente
qwen-plus Equilibrio rendimiento/costo
qwen-turbo Respuestas rápidas

Prueba Rápida:

  1. Abre cualquier archivo .php, .jsx o .js en tu proyecto
  2. Escribe un comentario como: // crear una función que...
  3. Presiona Ctrl+Espacio o activa el autocompletado de Qwen
  4. Si Qwen te sugiere código = ✅ ¡Funciona!
🎉 ¡Lo hiciste! Qwen Coder ahora tiene acceso a los modelos reales de Qwen. Puedes empezar a trabajar en tu proyecto.

❌ Si ves "No model matching":

Soluciona:
  • Verifica que tu API Key sea correcta
  • Comprueba que tu conexión a internet es estable
  • Reinicia VS Code completamente
  • Intenta en una ventana nueva de VS Code
  • Si aún no funciona, verifica en DashScope que tu cuenta tiene acceso a los modelos

Tu Workspace paginaRE:

Ya está configurado para que Qwen vea tus archivos:
📁 C:\xampp\htdocs\paginaRE
├── 📁 backend
├── 📁 frontend
└── coordination.html (panel de coordinación)

Próximos Pasos:

  1. Abre el panel de coordinación: http://localhost/paginaRE/coordination.html
  2. Comienza a usar Qwen: Ctrl+Alt+I o usa el chat inline en VS Code
  3. Ambos (Claude en terminal + Qwen en VS Code) pueden trabajar en paralelo
🚀 Flujo de trabajo recomendado:
1. Claude Code (terminal) → Backend, APIs, lógica de negocio
2. Qwen Coder (VS Code) → Frontend React, componentes, UI
3. Ambos → Coordinación via coordination.html
